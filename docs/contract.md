# Контракт API

## Пицца

| Поле      | Тип    | Описание                           |
|-----------|--------|------------------------------------|
| id        | строка | код пиццы, например p-1            |
| name      | строка | название, не пустое                |
| sizeCm    | число  | диаметр в см, больше 0             |
| price     | число  | цена в BYN, больше 0               |
| available | число  | сколько пицц доступно, не меньше 0 |
